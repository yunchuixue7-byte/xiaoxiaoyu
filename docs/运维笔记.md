## 四、插件

| 参数 | 当前值 | 说明 |

## 八、当前已知限制

| 限制 | 原因 |
|---|---|
| 唱歌只是「念歌词」 | TTS 不是歌声合成 |
| 语音有电话感 | 24kHz + QQ 语音压缩 |
| 空间点赞/评论做不到 | NapCat 该功能未发布 |
| 查空间访问申请 | 空间通知不走消息通道 |
| 群语音偶发失败 | edge-tts 服务不稳定（已加清洗+重试） |
